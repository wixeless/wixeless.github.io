## How the site works

- `index.html` holds the page content and a small script for the theme switch.
- `style.css` holds all styles. No build step.
- `_config.yml` keeps this README out of the published site.
- To update the page, edit `index.html` or `style.css` and push to the default branch. GitHub Pages republishes in about a minute.
